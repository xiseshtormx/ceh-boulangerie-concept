# Фотографии секции «О Цехе»

В блоке установлены две фотографии, приложенные пользователем 30.10.2026. Неизменённые PNG размером 960 × 1280 сохранены в `source-images/about/`. Для страницы изготовлены JPEG с качеством 93: `about-interior.jpg` (306 КБ) и `about-product.jpg` (477 КБ). Ретушь, удаление фона и генерация не применялись.

- `#about-interior`: интерьер с жёлтыми шторами и витриной. Большой вертикальный кадр 3:4, слева и выше второго снимка.
- `#about-product`: цельная фотография стола с круассанами и кофе. Вертикальный кадр 3:4 на переднем плане; фон стола сохранён.

На desktop фотографии мягко смещаются внутри обрезающих контейнеров в противоположных направлениях. Небольшой запас масштаба скрывает края при движении. Контейнер продукта отдельно проходит более длинную траекторию; интерьер движется медленнее. На мобильных внутренний параллакс отключён и фотографии видны целиком.

Для последующей замены поменяйте `src`, `alt`, `width`, `height` изображений в `scripts/compose-pages.mjs`, сохраните источник в `SOURCES.md` и выполните `npm run build`. Сгенерированный `index.html` вручную редактировать не нужно. Прежние SVG-слоты не загружаются страницей.

`about.js` использует существующую локальную GSAP: одна обратимая timeline, desktop `scrub: 1`, нативный CSS sticky, диапазон секции 270svh и финальная пауза 16%. Буквы начинают появляться при выходе hero из кадра. На компактных экранах — естественная прокрутка с уменьшенным движением; reduced motion и отсутствие JavaScript оставляют собранную статичную композицию.
