# Цех — сначала круассан

Самостоятельная digital-концепция кофейни-пекарни. Почти чёрное пространство, один круассан в hero, спокойная типографика Prata / Golos и настоящие фотографии пользователя из ВКонтакте.

## Запуск

Node.js 22+. Для запуска и сборки установка пакетов не требуется.

```sh
npm run dev
npm test
npm run build
```

Локально: `http://localhost:4322/`; результат сборки — `dist/`. Для изменения порта задайте `PORT`.

## Функциональность

- Чистый hero: один продукт, один заголовок, короткая строка и одна кнопка. Без слайдера, декоративных подписей и графики.
- Четыре food-секции. Фотографии каш и пасты меняются только по осознанному выбору; состав открывается в модальном окне. Автоматической или случайной ротации нет.
- Отдельное меню: 81 позиция, 11 категорий, поиск с поддержкой е/ё, избранное, составы и восемь настоящих фотографий.
- Выбор в меню отражается в URL. Есть пустые состояния, восстановление после повреждённого LocalStorage и прямые ссылки на категории.
- Модальные окна с нативным управлением фокусом, Escape и закрытием по фону. Адреса раскрываются при наведении или нажатии; движение строк реализовано через FLIP transforms.
- `prefers-reduced-motion`, видимый клавиатурный фокус и мгновенные клавиатурные действия. Анимация не блокирует доступ к меню.

## Файлы

`scripts/compose-pages.mjs` формирует `index.html` и `menu/index.html` при сборке. `presentation.js` задаёт главы и порядок фотографий; `styles.css` и `app.js` отвечают за интерфейс. `menu-model.js` — фильтрация; `catalog.json` — данные. Источники описаны в `SOURCES.md`.

Главная использует готовую 3D-чашку из `coffee-scene-3d.js` и GLB из `assets/coffee/3d/`. В `scripts/compose-pages.mjs` на секции кофе задан `data-coffee-renderer="3d"`. Нативная прокрутка через `coffee-story.js` управляет исходной анимацией: наклон чашки, горизонтальная поверхность, наполнение, струя, капли и пар воспроизводятся в обе стороны. Модели, PBR-карты и студийное освещение сохранены. `coffee-crema.js` добавляет локальное образование пенки в материале вместо проявления всего слоя через общую прозрачность; состояние определяется только прогрессом прокрутки. Корпус чашки оптически выровнен с центром текста; после остановки прокрутки WebGL не перерисовывается непрерывно. При `prefers-reduced-motion`, экономии трафика, малом объёме памяти или ошибке загрузки остаются соответствующий 3D-постер и текст без длинной прокрутки. Прежний фотографический модуль и оригиналы сохранены как исходные материалы, но не используются активной сценой.

Для повторного изготовления масок потребуется Sharp 0.34+ (`npm install --no-save sharp`), затем `node scripts/prepare-photos.mjs`. Эта операция не нужна для запуска и сборки сайта: готовые WebP уже включены.

Технический предпросмотр сохранён отдельно: `coffee-3d.html` (WebGL) и `coffee-3d.html?renderer=sequence` (отрендеренная последовательность). Его GSAP-контролы не переносятся на главную. GLB лежат в `assets/coffee/3d/`, Blender-проект, скрипты и инструкция — в `coffee-3d/README.md`, оригиналы моделей — в `coffee-3d/models/`. Сами GLB статические; анимацию рассчитывает готовый браузерный модуль. Локальные библиотеки включены в `vendor/`, CDN не требуется.

Сайт — неофициальный концепт. Оформление и оплата заказа происходят в действующем сервисе пекарни.
