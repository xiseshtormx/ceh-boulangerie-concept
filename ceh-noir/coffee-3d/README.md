# Чашка и кофе для сайта «Цех»

Настоящие mesh-модели, построенные по присланным изображениям. Реконструкция по ракурсам, не фотограмметрия. Внешняя форма, внутренняя стенка, замкнутое дно, ножка и соединённая с корпусом ручка имеют объёмную геометрию. Керамика — диэлектрик с глянцевой глазурью, а не металлический материал.

**WebGL v5 / кофе v4 + глазурь v2:** в начале наливается тёмный кофе без пенки. Образование пенки запускается при заполнении от 56% до 98% объёма; под струёй остаётся неровный просвет, пузырьки перемещаются к краям. В WebGL локальная shader-маска `coffee-crema.js` формирует неоднородные участки, которые разрастаются и скапливаются у края, вместо одновременного проявления всего слоя. При полном наполнении сохраняется исходный финальный материал. Фотографические детали сохранены из присланного кадра; добавлены 16 540 процедурных микропор, связанные карты нормалей и шероховатости. Карты пенки — 2048 × 2048. GLB, Blender и отрендеренная последовательность не изменялись этой правкой; передавайте вместе `coffee-scene-3d.js`, `coffee-fluid.js` и `coffee-crema.js`.

Струя ускоряется и сужается при падении, имеет переменную толщину, небольшое отклонение и движущиеся капиллярные волны. Цвет — тёмный эспрессо с просвечивающими янтарными краями. Водная граница имеет IOR 1,335 и transmission 0,96; тёмную середину создаёт объёмное поглощение, attenuation distance около 1,684 мм. В WebGL длина пути луча уточняется по поперечному сечению струи; в Cycles луч проходит через настоящий замкнутый объём. Последняя корректировка осветляет карту цвета на 5% и ослабляет плотность поглощения на 5%. У поверхности струя расширяется, темнеет и входит в неровный венчик всплеска с несколькими приподнятыми язычками. От удара расходятся волны и отрываются мелкие капли. При закрытии подачи сигнал проходит сверху вниз; последние капли падают отдельно, затем поверхность успокаивается. Отдельные карты цвета, шероховатости и нормалей струи — 256 × 1024, без нарисованных белых бликов.

Уровень определяется интегралом подачи и объёмом полости при текущем наклоне, с небольшим начальным слоем для устойчивой радиальной сетки. Жидкость остаётся под действием мировой вертикали. Верх объёма закрывает отдельная деформируемая поверхность: второй плоской крышки, перекрывающей воронку и волны, нет. В Blender геометрия запечена на каждом из 150 кадров; UV-сдвиг и маска у струи воспроизводятся нативными shader nodes, соответствующими WebGL. Это управляемая процедурная анимация, а не CFD/Mantaflow. Мелкие пульсации формы струи — художественная детализация поверх объёмного заполнения.

## Что подключать

Оригиналы GLB сохранены в `coffee-3d/models/`; сайт использует идентичные файлы в `assets/coffee/3d/`:

| Путь на сайте | Содержимое | Размер |
| --- | --- | --- |
| `/assets/coffee/3d/cup.glb` | Только пустая чашка | около 1,02 МиБ |
| `/assets/coffee/3d/ceh-coffee.glb` | Полная чашка, объём кофе, поверхность, crema, пузырьки | около 9,62 МиБ |
| `/assets/coffee/3d/ceh-coffee-pouring.glb` | Зафиксированное промежуточное состояние с наливом и каплями | около 9,90 МиБ |
| `/assets/coffee/3d/coffee-liquid.glb` | Кофе без чашки | около 8,61 МиБ |
| `/assets/coffee/3d/coffee-stream.glb` | Отдельная объёмная струя с картами материала | около 234 КиБ |

Для самостоятельного `ceh-noir` идентичные файлы лежат в `assets/coffee/3d/`. Размеры в метрах, ось вверх в GLB — `+Y`, дно чашки — около `Y=0`, высота — 66,75 мм, диаметр — 95,2 мм. Ручка направлена вправо, вдоль `+X`. В Blender вертикаль — `+Z`.

**GLB статические.** Наливание в браузере создаёт `coffee-scene-3d.js`, деформируя настоящие mesh-поверхности и струю. В `.blend` та же анимация запечена в shape keys и ключи трансформаций, поэтому воспроизводится без внешних обработчиков. Это управляемая процедурная жидкость, не симуляция Mantaflow.

## Посмотреть

Из папки `ceh-noir`:

```powershell
npm run dev
```

- `http://localhost:4322/coffee-3d.html` — GLB + WebGL, управление скроллом, кнопками и ползунком.
- `http://localhost:4322/coffee-3d.html?p=.5` — середина налива.
- `http://localhost:4322/coffee-3d.html?renderer=sequence` — настоящая отрендеренная последовательность, Canvas2D.

Кнопки — элементы технического предпросмотра; в существующую страницу их переносить не требуется. На главной `ceh-noir` уже установлен `data-coffee-renderer="3d"` на `.coffee-section`: она использует этот же WebGL-модуль. Изменять генерируемую главную страницу нужно в `scripts/compose-pages.mjs`, затем `npm run build`.

Для отдельной интеграции:

```js
import { createCoffeeScene } from './coffee-scene-3d.js';
const scene = await createCoffeeScene(canvas, {
  modelUrl: '/assets/coffee/3d/ceh-coffee.glb',
  streamUrl: '/assets/coffee/3d/coffee-stream.glb',
  lowPower: innerWidth < 700,
});
scene.resize({ width: canvas.clientWidth, height: canvas.clientHeight, dpr: devicePixelRatio });
scene.render({ progress: 0.5 }); // 0 = пустая, 1 = полная; любой порядок и направление
// При удалении секции:
scene.dispose();
```

Разместите `steam-wisp.png` рядом с моделью. `espresso-crema.png` и `espresso-surface.png` уже встроены в GLB, дополнительные запросы для них не нужны. Скопируйте вместе с модулем `coffee-fluid.js`, `coffee-crema.js` и папку `vendor/three`. Статический GLB можно открыть любым glTF-просмотрщиком; для характерных бликов нужны студийный environment map и освещение. Один путь к GLB не создаёт освещение и анимацию автоматически.

Связка с GSAP ScrollTrigger, pin, scrub, освобождением секции и статичным вариантом находится в `coffee-preview-3d.js`. В конце используется существующий текст «И кофе. Взять с собой. Или остаться ещё немного.» и прежняя ссылка на напитки.

## Производительность и доступность

- 59 212 треугольников в чашке; кофе и струя — отдельные сетки. Поверхность: 128 сегментов и 40 радиальных колец, на телефоне — 96 и 24. Кольца плотнее у точки удара. Струя: 112 колец × 24 стороны, со сведёнными нормалями шва. 144 пузырька desktop / 80 mobile и капли рисуются instanced-вызовами. Поверхность и пенка используют общую расчётную геометрию и кэш индексов.
- Плотность пикселей ограничена 1,75 на desktop и 1,35 на mobile. Рендер запускается при изменении прогресса; автономного бесконечного RAF нет.
- При `prefers-reduced-motion` и экономии трафика технический предпросмотр показывает итоговый WebP без pin и загрузки GLB. При потере контекста остаются статичный кадр, текст и ссылка.
- Последовательность: desktop 1280 × 1280, mobile 640 × 640, по 150 RGBA WebP, 30 FPS / 5 секунд. Композиция и камера одинаковы. Canvas держит до 18 кадров desktop или 14 mobile и загружает не больше трёх кадров одновременно.
- При резком переходе к ещё не загруженному кадру Canvas временно сохраняет ближайший готовый; после декодирования показывает нужный. Скорость сети влияет на первый просмотр. WebGL-вариант после загрузки модели от сети не зависит.

## Blender и повторное создание

Проверено в **Blender 5.2.3 LTS**. Исходники построения тела и ручки сохранены в скрытой коллекции `Construction_Editable_Source`; финальная керамика объединена через voxel remesh. Нативная сцена — `ceh_coffee_scene.blend`, все текстуры упакованы внутрь.

Из папки `ceh-noir`, PowerShell (если Blender находится в другом месте, замените путь):

```powershell
$blenderExe = 'C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe'
& $blenderExe -b --factory-startup -t 8 -P coffee-3d/create_coffee_scene.py -- --build
& $blenderExe -b coffee-3d/ceh_coffee_scene.blend -t 8 -P coffee-3d/verify_scene.py
& $blenderExe -b coffee-3d/ceh_coffee_scene.blend -t 8 -P coffee-3d/create_coffee_scene.py -- --keys --size 1024 --samples 48 --overwrite
& $blenderExe -b coffee-3d/ceh_coffee_scene.blend -t 8 -P coffee-3d/create_coffee_scene.py -- --sequence --size 1280 --samples 32 --overwrite
```

Для повторной подготовки текстур из присланного референса: `python coffee-3d/prepare_coffee_texture.py` (Pillow и NumPy). Эти карты уже включены в комплект; для обычной сборки повторная подготовка не нужна. Логика жидкости для Blender находится в `coffee_dynamics.py`, нативная схема движения пенки — в `coffee_shader.py`; `.blend` воспроизводит уже запечённые кадры без импорта этих модулей.

Дополнительный качественный рендер ключевых кадров до 4K:

```powershell
& $blenderExe -b coffee-3d/ceh_coffee_scene.blend -t 8 -P coffee-3d/create_coffee_scene.py -- --keys --4k --samples 96
```

Этот дополнительный режим требует отдельного времени на рендер; не увеличивайте 1280-последовательность простым апскейлом. Упаковщик проверяет именно 1280-мастер, чтобы случайно не смешать разрешения.

Преобразование PNG в WebP, проверка всех кадров, контактный лист и MP4:

```powershell
python -m pip install pillow numpy imageio-ffmpeg
python coffee-3d/pack_assets.py
# Если Blender ещё рендерит:
python coffee-3d/pack_assets.py --watch
```

Если Windows-команда `python` открывает Microsoft Store, используйте настоящий Python, например поставляемый с рабочим окружением Codex. Blender-скриптам нужен Python из Blender; `pack_assets.py` запускается обычным Python с Pillow и imageio-ffmpeg.

## Проверки

- `geometry-report.json`: замкнутость и объём финальной керамики.
- `scene-verification.json`: реальные деформированные mesh-объекты на кадрах 1, 24, 45, 75, 105, 130, 150; проверка попадания поверхности внутрь керамики через BVH и сохранения объёма чашки.
- `gltf-validation.json`: официальный Khronos glTF Validator, пять файлов.
- `sequence-verification.json`: полная декодируемость 150 desktop и 150 mobile кадров, фактические размеры и объёмы файлов.
- `renders/master/`: мастер-PNG с прямой альфой; `renders/keys/`: семь отдельных ключевых кадров; `contact-sheet.jpg`: просмотр этапов на чёрном фоне.
- `renders/keys-4k/frame_0150.png`: отдельно отрендеренный итоговый кадр 3840 × 3840; остальные семь контрольных кадров — 1024 × 1024. Веб-мастер — 1280 × 1280, мобильные WebP — 640 × 640.
