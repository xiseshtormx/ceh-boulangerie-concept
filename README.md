# Цех — сначала круассан

Текущая версия неофициального концепта кофейни-пекарни «Цех»: тёмная главная, меню с поиском и избранным, фотографии пользователя и интерактивная 3D-сцена кофе.

Сайт: https://xiseshtormx.github.io/ceh-boulangerie-concept/

## Разработка

Исходники находятся в `ceh-noir/`. Для запуска, тестов и сборки достаточно Node.js 22+.

```sh
npm run dev
npm test
npm run build
```

Локальный адрес: `http://localhost:4322/`. Готовый сайт: `ceh-noir/dist/`.

## Публикация

Изменения в `main` автоматически проходят тесты, собираются и публикуются в существующий GitHub Pages по прежнему адресу. Workflow: `.github/workflows/pages.yml`.

Подробности, источники фотографий и описание 3D-сцены: [README](ceh-noir/README.md) и [SOURCES](ceh-noir/SOURCES.md).
