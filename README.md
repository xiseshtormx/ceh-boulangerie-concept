# Цех boulangerie — портфолио-концепт

Неофициальный концепт сайта пермской кофейни-пекарни. Проект создан для демонстрации дизайна и разработки; он не является официальным сайтом или заказом компании.

**Опубликованная версия:** https://xiseshtormx.github.io/ceh-boulangerie-concept/

Полный художественный редизайн: предметная витрина, история пекарни, выбор завтраков, меню, кофейный натюрморт и четыре адреса. Единая система Prata + Golos Text, фарфор и вино. [Результаты проверки и ограничения](./QA-REDESIGN.md).

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Стек: Astro 6, TypeScript, CSS и локальные шрифты Fontsource. Команда `build` сначала выполняет `astro check`. Production-файлы создаются в `dist/`; GitHub Actions публикует их в GitHub Pages после push в `main`.

В конфигурации указан base path `/ceh-boulangerie-concept/`. При смене имени репозитория его нужно обновить.

## Материалы и источники

Предметные фотографии завтрака с тунцом и горячих круассанов предоставлены пользователем из материалов бренда. Имиджевые изображения выпечки, процесса и кофейного натюрморта созданы с помощью OpenAI ImageGen; они не подтверждают реальный ассортимент. Концептуальные изображения подписаны рядом с кадрами. Вымышленный интерьер больше не показывается.

Первый экран использует отдельный предметный визуал с прозрачностью; [происхождение и точный промпт](./src/assets/HERO-VISUAL.md). Настоящий знак «Цех» взят из действующего меню: [источник логотипа](./public/brand/SOURCE.md).

Кофейный кадр: [происхождение и точный промпт](./src/assets/COFFEE-VISUAL.md). Актуальная визуальная система и роли референсов описаны в [BRAND-PALETTE.md](./BRAND-PALETTE.md).
