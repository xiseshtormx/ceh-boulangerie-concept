# Цех boulangerie — рекламный web-концепт

Неофициальный рекламный концепт для пермской кофейни-пекарни. Текущая арт-дирекция собрана по присланным публикациям и меню бренда: молочное пространство, фисташковый и пыльно-розовый сезонные акценты, спокойный чёрный гротеск и редкий крупный курсив.

> Проект не является официальным сайтом или заказом компании. Предметные фотографии предоставлены пользователем из материалов бренда; имиджевые визуалы созданы специально для концепта.

## Что реализовано

- рекламный первый экран с продуктом, городом, четырьмя адресами и быстрым переходом к меню;
- управляемая горизонтальная витрина из шести конкретных позиций с кнопками, счётчиком, прогрессом и scroll-snap;
- доступная карусель производственного процесса с цельным кадром, кнопками, клавиатурой и scroll-snap;
- выбор из трёх реальных вариантов большого завтрака с обновлением состава и цены;
- меню с фотографиями горячих круассанов, пятью направлениями и проверенными примерами;
- отдельный визуальный сюжет пространства, без повторного кропа hero;
- четыре адреса и синхронизированная интерактивная схема;
- сценарий быстрого заказа вместо декоративного mockup телефона;
- FAQ с переходами в публичные источники;
- мобильное меню, фиксированное целевое действие, reduced-motion и видимые focus-состояния.

Разбор проблем первой версии находится в [`DESIGN-AUDIT-V2.md`](./DESIGN-AUDIT-V2.md), актуальная цветовая система — в [`BRAND-PALETTE.md`](./BRAND-PALETTE.md).

## Стек

- Astro 6 и TypeScript;
- CSS Grid/Flex, scroll-snap, IntersectionObserver;
- локальные шрифты Onest, Lora, Unbounded и IBM Plex Mono из Fontsource;
- Astro Image с адаптивной оптимизацией WebP;
- статическая production-сборка, готовая к размещению после согласования.

## Локальный просмотр

```sh
npm install
npm run dev
npm run build
npm run preview
```

Требуется Node.js 22 или новее.
