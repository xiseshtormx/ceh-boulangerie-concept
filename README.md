# Цех boulangerie — неофициальный концепт редизайна

Одностраничный рекламный сайт-концепт для пермской кофейни-пекарни «Цех boulangerie». Проект передаёт характер свежей выпечки через editorial-композицию, сгенерированные food-визуалы, scroll-анимацию круассана и интерактивный конструктор завтрака.

> Неофициальный концепт редизайна. Проект выполнен для демонстрации навыков и не является официальным сайтом «Цех boulangerie» или заказом компании.

## Что реализовано

- выразительный адаптивный hero с основными действиями;
- шесть карточек направлений витрины без выдуманных цен;
- закреплённая desktop scroll-сцена «Тесто → Хруст» на CSS-масках и TypeScript;
- упрощённая, не закреплённая версия механики на мобильных;
- рабочий конструктор завтрака без ложного расчёта стоимости;
- интерактивные категории меню;
- журнальная сетка атмосферы;
- четыре карточки адресов и интерактивная стилизованная схема Перми;
- самостоятельный концепт интерфейса приложения;
- FAQ с переходами в официальные источники;
- полноэкранное мобильное меню и фиксированная кнопка поиска адреса;
- SEO, Open Graph, favicon, sitemap при наличии `SITE_URL`, `prefers-reduced-motion` и клавиатурные focus-состояния.

## Стек

- Astro 6;
- TypeScript;
- компонентная структура `.astro`;
- CSS variables, CSS masks/clip-path, IntersectionObserver;
- локальные variable fonts Cormorant Garamond и Manrope из Fontsource;
- Astro Image для адаптивной оптимизации изображений;
- GitHub + готовый `netlify.toml` для публикации по схеме проекта Макса.

Тяжёлые animation/3D-библиотеки не используются.

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm install
npm run dev
npm run check
npm run build
npm run preview
```

Production-сборка появляется в `dist/`.

## Структура контента

Все меняющиеся данные вынесены из компонентов:

- `src/data/brand.ts` — имя, тексты hero, юридическая подпись, палитра;
- `src/data/products.ts` — продуктовые карточки и статусы демонстрационных визуалов;
- `src/data/categories.ts` — направления меню;
- `src/data/branches.ts` — адреса, часы, особенности, маршруты и позиции на схеме;
- `src/data/links.ts` — меню, ВКонтакте, 2ГИС, Google Play;
- `src/data/faq.ts` — вопросы, ответы и источники;
- `src/data/contacts.ts` — подтверждённый email и статус телефона;
- `src/data/images.ts` — пути, alt-тексты и происхождение изображений.

Изображения лежат в `src/assets/` и заменяются без изменения сетки при сохранении имён файлов или обновлении импортов компонентов.

## Подключение формы или endpoint

Текущая версия не создаёт фиктивную систему заказа и не собирает пользовательские данные: целевые действия ведут в публичное меню и приложение. Если позже потребуется собственная форма предзаказа:

1. добавить отдельный serverless endpoint;
2. хранить URL и секреты только в переменных окружения хостинга;
3. добавить явное согласие на обработку данных;
4. показывать подтверждение только после успешного ответа сервера;
5. не отправлять данные в сторонние сервисы без раскрытия получателя.
