# Цех boulangerie — «Слои в деле»

Полностью переработанный неофициальный рекламный концепт для пермской кофейни-пекарни. Версия V2 сознательно отказывается от универсальной «бежевой editorial-пекарни» в пользу визуального языка городского производства: номер партии, время смены, сталь, сигнальный красный и крупная кириллическая типографика.

> Проект не является официальным сайтом или заказом компании. Сгенерированные изображения не показывают реальные блюда и интерьеры «Цех boulangerie».

## Что реализовано

- рекламный первый экран с продуктом, городом, четырьмя адресами и быстрым переходом к меню;
- горизонтальная витрина из шести конкретных позиций и цен публичного меню;
- доступная карусель производственного процесса с цельным кадром, кнопками, клавиатурой и scroll-snap;
- выбор из трёх реальных вариантов большого завтрака с обновлением состава и цены;
- «меню-манифест» с пятью направлениями и проверенными примерами;
- отдельный визуальный сюжет пространства, без повторного кропа hero;
- четыре адреса и синхронизированная интерактивная схема;
- сценарий быстрого заказа вместо декоративного mockup телефона;
- FAQ с переходами в публичные источники;
- мобильное меню, фиксированное целевое действие, reduced-motion и видимые focus-состояния.

Разбор проблем первой версии, конкурентные ориентиры и новая арт-дирекция находятся в [`DESIGN-AUDIT-V2.md`](./DESIGN-AUDIT-V2.md).

## Стек

- Astro 6 и TypeScript;
- CSS Grid/Flex, scroll-snap, IntersectionObserver;
- локальные шрифты Unbounded, Onest и IBM Plex Mono из Fontsource;
- Astro Image с адаптивной оптимизацией WebP;
- статическая production-сборка, готовая к размещению после согласования.

## Локальный просмотр

```sh
npm install
npm run dev
npm run build
npm run preview
```

Требуется Node.js 22 или новее.
